# IELTS Listening — Test 3

A full forty-question IELTS Listening test with the four recordings included and
the official answer key built in.

```
index.html        the whole test — questions, marking, certificate
audio/part1.mp3   Section 1 — enrolling on a language course
audio/part2.mp3   Section 2 — town transport and a street map
audio/part3.mp3   Section 3 — choosing science courses with a tutor
audio/part4.mp3   Section 4 — a lecture on the city of the future
README.md         this file
```

The page looks for the recordings in an `audio` folder first, and if they are not
there it looks for `part1.mp3` to `part4.mp3` beside `index.html`. Either layout
works, so it does not matter whether GitHub keeps the folder.

## Putting it on GitHub Pages

1. Create a new **Public** repository, for example `IELTS-Listening-Test-3`.
2. Click **uploading an existing file**, drag in `index.html`, `README.md` and the
   four MP3s (about 21 MB). Wait for all of them to finish, then **Commit changes**.
3. **Settings → Pages →** Source *Deploy from a branch*, branch **main**, folder
   **/ (root)**, then **Save**.
4. After a minute the live link appears. Open it, go to Section 1 and press play
   before you share it with students.

## What's in the test

- **Section 1** — notes about available courses (7 gaps, three words and/or a
  number) and a choose-three question about what to bring to the first class.
- **Section 2** — matching five features to tube, train or bus, then labelling a
  town map with letters A to G.
- **Section 3** — matching an advantage to each course, then seven sentence gaps
  (two words each).
- **Section 4** — a table on the future city (seven gaps) and a three-part
  question on types of city-centre accommodation.

Nothing to set up: the key is built in and marking is automatic. A **Mark Section**
button scores one section on its own, and **See my full result** gives the score
out of 40, a bar for each section, an estimated band and a certificate.

**Marking is deliberately forgiving.** A right answer with a harmless extra word —
*from industry*, *extra seminars*, *made of glass* — is marked correct, with a note
reminding the student to write only the short form in the real exam. Articles,
hyphens and capitals are ignored, so *third term* and *the 3rd term* both score,
as do *wind farms* and *windfarms*. Questions 8–10 and 38–40 are marked in any
order. Genuinely wrong answers are still wrong.

The **ع** button shows Arabic instructions for each task.
